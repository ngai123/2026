Unique Tool — #1 of 2
Thermal Scanning

thermal_scan

Simulates an infrared sensor sweep at the drone's current GPS position, returning every survivor within a 100 m radius — with critical-injury flags and exact coordinates — all in a single tool call.

Sensor Simulation 100 m Radius Persistent via SQLite

Why it's irreplaceable

No generic MCP server has a sensor model. thermal_scan is the only way an AI agent can "see" survivors in our simulation. Without it, the rescue swarm is blind — it moves but cannot act. Every rescue decision flows downstream from this single tool's output.

Unique Tool — #2 of 2
Team Sector Sweep

get_team_waypoint
advance_team_sector

A collective consensus mechanism built into the tool layer. All 5 drones sweep one sector simultaneously in assigned rings (OUTER / MIDDLE). advance_team_sector() only promotes to the next sector when every single drone has finished its role — enforced by the server, not the AI.

Multi-Agent Consensus 5 Sectors · 5 Drones Server-Enforced

Why it's irreplaceable

No AI prompt can reliably coordinate 5 concurrent agents without race conditions. This tool pair bakes the coordination into the server itself: agents just call get_team_waypoint() and trust the server to gate the next sector — making the swarm stateless from the LLM's perspective.

How Coordination Works
5 Sectors — One at a Time
Alpha 0°–72° Bravo 72°–144° Charlie 144°–216° Delta 216°–288° Echo 288°–360°

How It All Connects

The Mission Flow

26 tools chain into a two-phase rescue operation. Each phase has a strict tool order.

Phase 1 — Map

get_active_drones Discover fleet at runtime
get_team_waypoint Get sector waypoint per drone
move_drone_to Fly to waypoint coordinates
thermal_scan ★ Detect survivors at position
advance_team_sector ★ Consensus → next sector
Repeats across all 5 sectors until 100% mapped.

Phase 2 — Rescue

get_known_survivors Load all detected survivors
get_battery_status Verify drone can reach target
move_drone_to Route to survivor (critical first)
thermal_scan ★ Confirm position, extract
get_mission_status Check mission_complete flag
Continues until all 600 survivors are rescued.
Both unique tools — thermal_scan and advance_team_sector — appear in both phases. They are the engine of every rescue action.
