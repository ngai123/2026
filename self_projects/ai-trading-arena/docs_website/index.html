Trading Engine (engine.py)

The heart of the application is the APScheduler-driven 24/7 loop.

The Loop Tick

Every N minutes, the system wakes up and gathers market state, technicals, and on-chain metrics to form a "Desk Briefing".

Paper Execution

Models return strict JSON decisions (long/short/flat). The engine calculates slippage, fees, and updates their SQLite paper portfolio.

AI Agents & Prompting

Models are heavily prompted to avoid closet-indexing and target alpha against a Buy & Hold benchmark.

SYSTEM PROMPT EXCERPT
"Your ONLY score is ALPHA: your return MINUS a passive 100% Buy & Hold of the same market. Matching Buy & Hold = 0 alpha = FAILURE... Each position uses LEVERAGE (1x..3x) and posts margin..."
  • Strict Schema: Forces valid JSON via Pydantic (`schemas.AgentTurn`).
  • Fan-out: Queries all agents concurrently using `asyncio.gather`.
  • Error Fallback: If a model hallucinates malformed JSON, it is logged and defaults to 'hold'.
