# 段永平思维分析包

三种工具，对应三种用法：

## 1) 原则提炼（先读这个）
`段永平_思维原则.md` —— 把1万条发言压缩成8条核心原则，每条配他本人高赞原话+年份。
适合快速建立"他怎么想"的整体框架。

## 2) 逐公司案例（看演变）
`companies/` —— 每个文件是他关于某公司的全部发言，**按时间顺序**排列：
  苹果 / 茅台 / 腾讯 / 拼多多 / 网易 / 泡泡玛特 / 特斯拉 / 巴菲特伯克希尔
用法：从头读到尾，就能看到他对一家公司的看法如何随年份演变（如拼多多"看不懂但不卖"）。

## 3) 主题原文 + 自由提问
`themes/` —— 8个主题（本分/能力圈/商业模式/企业文化/平常心/估值买卖/分红回购/长期）的全部原始发言。
`../scripts/search.py` —— 关键词检索：
    python3 ../scripts/search.py "护城河"          # 按点赞排序
    python3 ../scripts/search.py "茅台" --date     # 按时间排序
    python3 ../scripts/search.py "margin" --n 40   # 显示40条

## 建议的分析流程
1. 读 `段永平_思维原则.md` 建立框架。
2. 挑一家你感兴趣的公司，通读 `companies/` 里对应文件，看他的逻辑链。
3. 有疑问就 `search.py` 调原文，或把某个 themes/ 文件（够小）贴进 Claude 追问。
